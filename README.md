# hatchunit

Hatch digests and unit fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/hatchunit/

## Install / run

```bash
git clone https://github.com/theworker02/hatchunit.git
cd hatchunit
node src/cli.js
node --test
```
